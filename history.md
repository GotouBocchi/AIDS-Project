# Changelog

All notable changes to the Aids-Project will be documented in this file. Versioning follows semantic versioning principles.

## [1.0.0] - 2026-10-22
### Added
- **Core Framework:** Initialized Ren'Py 8.3.4 project structure with Live 2.5D visual novel architecture.
- **AI Integration:** Configured local Dolphin-Qwen2.5 (`dolphin-qwen2.5:3b`) via Ollama for free-form player text input and real-time dialogue generation.
- **Character Personas:** Established baseline character profiles with standard narrative ending biases (Elena for Happy Endings, Lyra for Bittersweet/Sad Endings, Vesper for Dramatic/Bad Endings).
- **Optimization and Standards:** Pinned tool versions (`Ruff v0.6.9`, `Mypy v1.11.2`, Ren'Py Built-in Lint) and weak PC hardware constraints.
- **Documentation and File Map:** Clean, non-bloated markdown files (`gemini.md`, `docs/structure.md`, `docs/optimization.md`, `docs/standards.md`, `CHANGELOG.md`).
