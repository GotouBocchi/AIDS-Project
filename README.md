# AIDS-Project: AI-Driven Story

**AIDS-Project** is an experimental visual novel framework built on the Ren'Py engine. Unlike traditional visual novels with static branching paths, this project aims to create a truly dynamic experience where an AI engine generates the story scenario, climax, and resolution in real-time.

## Project Vision
The goal is to leverage Large Language Models (LLMs) to break away from pre-written scripts, allowing for:
- **Infinite Replayability:** Every playthrough results in a unique narrative.
- **Dynamic Response:** The story adapts to player choices with context-aware AI generation.
- **AI-Crafted Climax:** A narrative engine that understands tension and builds toward a unique conclusion.

## Technical Overview
- **Engine:** [Ren'Py](https://www.renpy.org/)
- **Core Technology:** AI-driven text generation and state management.
- **Architecture:** Modular Python/Ren'Py hybrid designed for dynamic content injection.
